# Networking

## Purpose
Build practical networking skills with Azure Virtual Network, IPv4 addressing, subnetting, routing, Network Security Groups (NSGs), Azure Firewall, DNS, and secure connectivity.

## Networking Labs

| Lab | Topic | Skills |
| --- | --- | --- |
| [Lab 01: Build a VNet with public and private subnets](./LAB-01-vnet-and-subnets.md) | VNet fundamentals | CIDR, subnets, NSGs, system routes, public IP concepts |
| 02 | User-defined routes and next hops | Planned |
| 03 | NSG rules and traffic filtering | Planned |
| 04 | DNS and connectivity troubleshooting | Planned |
| 05 | VPN Gateway and site-to-site concepts | Planned |
| 06 | Network monitoring and traffic analysis | Planned |

## Recommended Learning Order
1. Complete Lab 01 and understand the VNet address space and subnet boundaries.
2. Learn Azure system routes and user-defined route tables.
3. Practice NSG rules and compare them with Azure Firewall.
4. Explore private connectivity, DNS, VPN Gateway, and monitoring in later labs.

## Lab Documentation
Every lab should include an objective, prerequisites, topology, IP addressing plan, configuration steps, validation, troubleshooting, security considerations, cleanup, and lessons learned.
