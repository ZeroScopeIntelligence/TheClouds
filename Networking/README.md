# Networking

## Purpose
Build practical networking skills with Amazon VPC, IPv4 addressing, subnetting, routing, internet gateways, security groups, network ACLs, DNS, and secure connectivity.

## Networking Labs

| Lab | Topic | Skills |
| --- | --- | --- |
| [Lab 01: Build a VPC with public and private subnets](./LAB-01-vpc-and-subnets.md) | VPC fundamentals | CIDR, subnets, route tables, internet gateway, security boundaries |
| 02 | Routing and NAT | Planned |
| 03 | Security groups and network ACLs | Planned |
| 04 | DNS and connectivity troubleshooting | Planned |
| 05 | Site-to-site VPN concepts | Planned |
| 06 | Network monitoring and traffic analysis | Planned |

## Recommended Learning Order
1. Complete Lab 01 and understand the VPC address space and subnet boundaries.
2. Learn how public and private route tables control traffic.
3. Compare security groups (stateful) with network ACLs (stateless).
4. Explore DNS, VPC endpoints, NAT, and VPN connectivity in later labs.

## Lab Documentation
Every lab should include an objective, prerequisites, topology, IP addressing plan, configuration steps, validation, troubleshooting, security considerations, cleanup, and lessons learned.
