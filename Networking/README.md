# Networking

## Purpose
Build practical networking skills with Google Cloud VPC networks, IPv4 addressing, subnetting, routes, firewall rules, Cloud NAT, Cloud DNS, and secure connectivity.

## Networking Labs

| Lab | Topic | Skills |
| --- | --- | --- |
| [Lab 01: Build a VPC with public and private subnets](./LAB-01-vpc-and-subnets.md) | VPC fundamentals | CIDR, regional subnets, routes, firewall rules, external IP concepts |
| 02 | Routes and Cloud NAT | Planned |
| 03 | VPC firewall rules | Planned |
| 04 | Cloud DNS and connectivity troubleshooting | Planned |
| 05 | Cloud VPN concepts | Planned |
| 06 | Network monitoring and traffic analysis | Planned |

## Recommended Learning Order
1. Complete Lab 01 and understand global VPC networks and regional subnet boundaries.
2. Learn routes, next hops, and Cloud NAT.
3. Practice VPC firewall rules and understand target selection.
4. Explore Cloud DNS, Cloud VPN, and network monitoring in later labs.

## Lab Documentation
Every lab should include an objective, prerequisites, topology, IP addressing plan, configuration steps, validation, troubleshooting, security considerations, cleanup, and lessons learned.
